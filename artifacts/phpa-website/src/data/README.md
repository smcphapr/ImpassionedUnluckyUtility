# PHPA content updates

These files hold routine content for future PHPA board members:

- `events.ts` — add or update events here. Use an ISO date such as `2026-10-08`; the homepage automatically selects the earliest event whose date is today or later. `events.json` mirrors the same field shape for easy handoff or export.
- `opportunities.ts` — add or remove confirmed shadowing, clinical experience, volunteering, and research listings here. `opportunities.json` mirrors the same current entries.
- `board.ts` — add, remove, or update board members and roles here. `board.json` mirrors the same current entries.
- `siteContent.json` — update homepage wording and the destination links used by the hero and “What are you looking for?” cards.

Keep event dates valid and leave `date` empty only for an event that is still a placeholder. Do not publish unconfirmed organizations, dates, contact details, or links.
